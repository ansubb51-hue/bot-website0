How to read this page

  • Online — a fresh report arrived and the bot said it is running.
  • No recent report — the last report is older than 30 minutes (or the reporter is switched off). This does not prove the bot is down.
  • Not connected / Unavailable — no stats file or API is connected to this website yet, so nothing is shown instead of guessing.

Instead of this page you can also check whether SK1.0 shows as online in your Discord member list. Problems? Ask in the support server.
