This Privacy Policy explains what the Discord bot SK1.0 (“the bot”) stores and why. The bot is run by . Contact: .

1. What the bot stores

The bot only stores data that its features need. Depending on which features a server uses, this can include:

FeatureData stored
Server settingsServer (guild) ID, prefix, language, chosen channels and roles, feature switches and messages configured by server admins.
XP, levels, economy, shop, games, animals, marriagesDiscord user ID and server ID with XP, level, coin balance, inventory items, game totals, animals and marriage status.
ModerationWarnings, moderation cases (action, moderator ID, target user ID, reason, time), staff notes, quarantine status, blacklist / whitelist entries.
Security (anti-nuke, guards)Whitelist, saved copies of channel and role structure used for restoring after an attack, and an action log.
VerificationA verification log (user ID, result, time).
Tickets and applicationsTicket records (channel ID, opener ID, status, claimer). A transcript is created only when a staff member runs the transcript command. Application questions and answers submitted by members.
Invite trackerInvite codes, who joined through which invite, join / leave events and invite rewards.
Community toolsGiveaways and entries, reaction / button roles, temporary roles, suggestions, polls, events, custom commands, reminders, AFK status and starboard posts.
Usage and diagnosticsCommand usage counts, an activity log, error records and performance samples (latency, memory, CPU) used to keep the bot working.
Web admin panel (if the host enables it)Login session identifiers and an audit log of changes made in the panel.

To work, the bot receives Discord events through the permissions and intents it is granted (servers, members and message content). Message content is processed to run commands and AutoMod rules; this site does not claim the bot keeps a copy of normal chat messages beyond what the features above describe.

2. Why the data is used

  • To provide the bot's commands and features.
  • To protect servers (moderation, AutoMod, security, verification).
  • To find and fix errors and keep the bot running.
