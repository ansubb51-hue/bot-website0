How it works

Ready in four steps

No coding needed. If you can click a button in Discord, you can set up SK1.0.

1

Invite the bot

Press Add to Discord, choose your server and click Authorize. You need the Manage Server permission on that server.

2

Give the right permissions

Keep the permissions ticked on the invite screen. Then, in Server Settings → Roles, drag the SK1.0 role above the roles it should manage.

3

Configure features

Start with the help menu, then switch on what you need.!help!setlogs #mod-logs!automod on

4

Use commands

Default prefix is ! — sk also works. … commands also work as slash commands.!ban @user spamming/help

Tip: change the prefix any time with !setprefix.

Add SK1.0 to your server

The invite uses Discord's official OAuth2 page. You choose the server and see every permission before you approve. Administrator is not required.

Which permissions does the invite ask for?
View Channels, Send Messages, Embed Links, Attach Files, Read Message History, Add Reactions, Use External Emojis, Manage Messages, Manage Roles, Manage Channels, Manage Server, Manage Nicknames, Manage Events, Manage Webhooks, Kick Members, Ban Members, Timeout Members, View Audit Log and Create Invite. Features you don't use simply won't need them — you may untick any permission on the Discord screen.

Support

Need help?

Check the answers below first. If you are still stuck, ask in the support server.

💬 Join Support Server
The bot is online but does not answer my commands
Check that SK1.0 can View Channel and Send Messages in that channel, that you used the right prefix (default ! — or sk ), and that the channel or your user is not on an ignore list (!ignorechannel, !ignoreuser). Mentioning the bot (for example @SK1.0 help) also works as a prefix.
Ban / kick / role commands say “missing permissions” or “hierarchy”
Discord only lets a bot manage members and roles that sit below its own highest role. Open Server Settings → Roles and drag the SK1.0 role higher. The bot also needs the matching permission (Ban Members, Kick Members, Manage Roles …).
Who can use staff commands?
Each command lists the permission it needs on the Commands page (for example Ban Members). Admins can also set staff roles with !setadminrole, !setmodrole and !sethelperrole.
How do I change the prefix?
Use !setprefix <new prefix>. The prefix sk and mentioning the bot keep working as alternatives. Slash commands do not need a prefix.
How do I set up welcome messages, logs or tickets?
Welcome: !setwelcome #channel then !welcometest. Logs: !setlogs #channel. Tickets: !ticketpanel in the channel where members should open tickets. Every command has an example on the Commands page.
Which data does the bot store?
Only what its features need (settings, XP/economy, warnings, tickets, and similar). The full list is in the Privacy Policy.
The bot looks offline on this website
This site can only show a status when the bot's host sends reports. If the status page says “Not connected” or “No recent report”, it means no report arrived — it does not by itself prove the bot is down. Check whether the bot is online in your Discord member list.
